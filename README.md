# flybrain — Drosophila Connectome & Spiking Neural Network

Whole-brain simulation of the fruit fly *Drosophila melanogaster* built on the
FlyWire connectome (~139 000 neurons, v783), with a spiking leaky
integrate-and-fire network in Brian2, graph analytics, a cell-type classifier
and connectome-constrained training.
